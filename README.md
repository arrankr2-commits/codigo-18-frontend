#COMANDOS DE GIT
## comando para iniciar una carpeta 
git init 
## comando para ver el estado de mis archivos 
git status 
## comando para agregar mis archivos al stage de git
git add .
## comando para crear una versión de nuestr código junto a un comentario 
git commit -m "feat: se creó el reto 1 para el portafolio"

feat: feature(nueva funcionalidad)
fix: (reparar algo)
chore:(cosas repetitivas)
styles:(modifico la apariencia de la web)
